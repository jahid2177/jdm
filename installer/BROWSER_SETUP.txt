JAHID DOWNLOAD MANAGER - GUIDED WINDOWS BROWSER SETUP
Version 2.0.0 | Developer: Md Jahidul Islam

The Windows installer offers an "Open guided Chrome / Edge integration setup"
task. Leave it selected when installing JDM. On first launch JDM opens the
Browser Integration Setup screen. You can reopen it at any time using the
extension/puzzle icon in JDM's Windows toolbar.

CHROME OR MICROSOFT EDGE

1. On the JDM Browser Integration Setup screen, click "Copy extension folder".
2. Click "Open Google Chrome extensions" or "Open Microsoft Edge extensions".
   Alternatively open chrome://extensions or edge://extensions manually.
3. Enable Developer mode and click "Load unpacked". Paste/select the folder
   copied in step 1. Chromium requires user approval to enable this extension;
   Windows installers cannot silently sideload an unpacked extension.
4. Return to JDM and click "Detect and connect automatically" for the browser.
   JDM identifies the approved extension from its browser profile and writes
   its Windows per-user Native Messaging registration automatically.
5. If detection says no extension was found, copy the 32-letter Extension ID
   shown at the browser extensions page, paste it into JDM, and click
   "Connect ... using ID". No PowerShell command is required.
6. Restart the browser, keep JDM running, and choose "Download link with JDM"
   on a direct HTTP(S) link or use the extension toolbar button.

The installer includes browser_extensions\chromium and jdm_native_host.exe.
Do not move those files after installing JDM. If you change the installation
directory, reopen the Browser Integration Setup screen and connect again.

SECURITY AND LIMITS

Browser installation is opt-in, requires the browser's own user approval,
and cannot bypass organization/device browser policies. Native Messaging
registration uses the current Windows user's registry (HKCU) and needs no
Administrator permission. Only user-approved JDM extension IDs are allowed.
The setup assistant never imports passwords, private browser cookies, or DRM
streams. The extension and JDM must both be running to send links.

Firefox remains a manual/development-only temporary add-on:
  about:debugging#/runtime/this-firefox -> Load Temporary Add-on
  Select browser_extensions\firefox\manifest.json
Its native host can be registered through browser_integration\install_windows.ps1
with -Browser Firefox, subject to the device's PowerShell execution policy.

On Windows uninstall, the installer removes the Chrome/Edge JDM native host
registrations. Browser extensions loaded manually may need to be removed
separately from the browser's Extensions page.
